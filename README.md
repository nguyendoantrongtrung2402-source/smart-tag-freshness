# FreshTag V7

Files required together:
- app.py
- requirements.txt
- freshtag_camera/index.html
- optional: model.joblib

The custom camera component requests browser camera permission and prefers the rear camera.
HTTPS is required for getUserMedia; Streamlit Community Cloud provides HTTPS.

Local syntax check was performed for Python. Browser/runtime camera behavior must be tested on the target phone/browser.
